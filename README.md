# 🚀 HIREX Recruitment System

**Hire smarter, not harder.** HIREX is a comprehensive recruitment platform built to streamline the end-to-end hiring process—from job posting and resume parsing to candidate evaluation and final selection.

---

## ✨ Key Features
*   **Intelligent Parsing:** Automatically extract key skills and experience from resumes.
*   **Candidate Ranking:** High-precision matching algorithms to identify top-tier talent instantly.
*   **Dynamic Workflow:** Customizable hiring stages (Screening, Technical, HR, Offer) tailored to your team's needs.
*   **Collaborative Hiring:** Centralized feedback and rating system for interviewers.

---

## 🛠️ Tech Stack
*   **Frontend:** React.js / Tailwind CSS
*   **Backend:** Python (FastAPI)
*   **Database:** PostgreSQL
*   **Authentication:** JWT / OAuth 2.0

---

## 🚀 Getting Started

### 1. Prerequisites
*   Node.js (v18+) or Python 3.10+
*   Docker (Optional for containerized deployment)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/your-username/hirex.git

# Install dependencies
cd hirex
npm install # or pip install -r requirements.txt
```

### 3. Environment Setup
Create a `.env` file in the root directory and add your credentials:
```env
DATABASE_URL=your_db_connection_string
API_SECRET=your_secret_key
```

### 4. Run the Application
```bash
npm run dev # or uvicorn main:app --reload
```
